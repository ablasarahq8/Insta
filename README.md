# دفتر أفكار إنستغرام

موقع تجمع فيه كل أفكارك للإنستغرام بمكان واحد، يقترح عليك أفكار خاصة بحسابك، يكتب لك الكابشن، وينشر أو يجدول على إنستغرام مباشرة.

## شنو يسوي

- **الخطة**: خطة تسويقية لمدة (شهر، ٣ شهور، ٦ شهور).
  - تختار أهدافك (متابعين، اشتراكات، مجتمع، بيع دورات...) وتحط الإطلاقات بتواريخها.
  - الذكاء الاصطناعي يبني: المراحل، مؤشرات القياس، خطة كل أسبوع (ثيم، تركيز، نسب القمع، الأهداف، CTA)، وجدول الإعلان عن كل إطلاق (متى تلمّح، متى قائمة الانتظار، يوم الإطلاق، آخر فرصة).
  - صفحة الأسبوع تاخذ ثيم الأسبوع ونسبه من الخطة، و«خطط لي الأسبوع» يمشي عليها ويغطي أحداث الإطلاق.
- **اللقطات**: مكتبة صور وفيديوهات B-roll تصورها مرة وحدة.
  - الذكاء الاصطناعي يقترح شنو تصور حسب مجالك وخطتك، مع نصايح التصوير.
  - تعلّم على اللي صورته وترفعه.
  - من أي ريل اضغط «🎙️ اكتبه من لقطاتي» يطلع لك سكربت فويس اوفر مقسم مشاهد على لقطاتك.
- **الأسبوع**: تقويم للأسبوع (من الأحد للسبت) تشوف فيه شنو بتنزل كل يوم.
  - كل منشور له **مرحلة قمع**: TOF (وعي وانتشار)، MOF (ثقة واهتمام)، BOF (تحويل وبيع).
  - وكل منشور له **هدف**: بيعي، تسويقي، جذب عملاء، فكاهي، أخبار، تقني، تعليمي، تفاعلي، خلف الكواليس.
  - شريط توازن يوريك نسبة كل مرحلة مقارنة بالنسبة المقترحة (TOF ٥٠٪ · MOF ٣٠٪ · BOF ٢٠٪)، وكم منشور من كل هدف، وينبهك إذا الأسبوع مو متوازن.
  - «✨ خطط لي الأسبوع»: الذكاء الاصطناعي يخطط أسبوع كامل متنوع ويكمّل على اللي حاطه، وتعتمده بضغطة (ينحفظ كمسودات بمواعيدها).
  - «+ ضيف» بأي يوم: منشور جديد أو فكرة من أفكارك اللي ما لها موعد.
- **أفكاري**: تكتب الفكرة بسرعة، وبعدين تفتحها وتضيف ملاحظات، كابشن، هاشتاقات، صور أو فيديو. كل فكرة لها حالة: فكرة ← مسودة ← مجدولة ← منشورة.
- **اقتراحات**: الذكاء الاصطناعي (Claude) يقرا ملف حسابك وأفكارك الموجودة ويقترح أفكار جديدة مع الهوك وطريقة التنفيذ والكابشن، وتضيفها لأفكارك بضغطة.
- **ملف الحساب**: المجال، الجمهور، الأسلوب، اللهجة، الأهداف، وأمثلة من منشوراتك، عشان تطلع الاقتراحات مناسبة لحسابك بالضبط.
- **النشر**: «انشر الحين» أو حدد موعد وخل الحالة «مجدولة» والموقع ينشرها بوقتها (يشيك كل دقيقة). يدعم صورة وحدة، كاروسيل (لين ١٠)، وريلز.

## التشغيل

```bash
npm install
cp .env.example .env   # وعبّي القيم
npm start              # http://localhost:3000
```

## الإعدادات (`.env`)

| المتغير | ليش |
|---|---|
| `ANTHROPIC_API_KEY` | للاقتراحات وكتابة الكابشن. من [console.anthropic.com](https://console.anthropic.com) |
| `IG_USER_ID` / `IG_ACCESS_TOKEN` | للنشر على إنستغرام |
| `PUBLIC_BASE_URL` | الرابط العام للموقع. إنستغرام يسحب الصور من رابط عام، فالصور المرفوعة ما تنتشر إلا إذا الموقع منشور على النت |
| `APP_PASSWORD` | اختياري: كلمة سر تحمي الموقع (اسم المستخدم أي شي) |

### ربط إنستغرام

1. حوّل حسابك إلى **Business** أو **Creator**.
2. سوّ تطبيق في [Meta for Developers](https://developers.facebook.com/) وضيف منتج **Instagram**.
3. طلّع Access Token فيه صلاحية `instagram_business_content_publish` (أو `instagram_content_publish` إذا الحساب مربوط بصفحة فيسبوك)، وخذ الـ Instagram User ID.
4. إذا استخدمت «Instagram Login» بدال فيسبوك، حط `IG_GRAPH_HOST=https://graph.instagram.com`.

> ملاحظة: الـ Access Token العادي ينتهي، استخدم توكن طويل المدة (60 يوم) وجدده.

## النشر على Render

1. ادخل [render.com](https://render.com) وسجّل بحساب GitHub.
2. **New** ← **Blueprint** ← اختار هالـ repo والفرع.
3. Render يقرا `render.yaml` ويطلب منك القيم: `ANTHROPIC_API_KEY`، `APP_PASSWORD` (كلمة سر الموقع)، و `IG_USER_ID` / `IG_ACCESS_TOKEN` (تقدر تخليها فاضية لين تربط إنستغرام).
4. **Apply** وانطر لين يخلص. الموقع يطلع على رابط مثل `https://insta-ideas.onrender.com`.

- البيانات والصور تنحفظ على Disk دائم (`/var/data`) فما تضيع مع التحديثات.
- `PUBLIC_BASE_URL` ما يحتاج تحطه، ياخذ رابط Render تلقائياً.
- لازم خطة **Starter** (المجانية ما فيها Disk والسيرفر ينام، فالجدولة ما تشتغل).
- أي تحديث ينرفع على الفرع، Render ينشره تلقائياً.

## التقنية

Node.js + Express، والواجهة HTML/JS بدون frameworks. البيانات تنحفظ في `data/db.json` والملفات المرفوعة في `data/uploads/` (أو بمسار `DATA_DIR` إذا محدد).
